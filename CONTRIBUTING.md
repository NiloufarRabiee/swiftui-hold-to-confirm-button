# Contributing

Contributions are welcome.

## Before opening a pull request

1. Keep changes focused and small.
2. Avoid adding third-party dependencies unless they are clearly necessary.
3. Preserve the component's simple SwiftUI API.
4. Add or update tests for behavior that can be tested.
5. Run:

```bash
swift build
swift test
```

## Pull requests

Explain what changed, why it changed, and any API impact.

By contributing, you agree that your contributions will be licensed under the MIT License used by this repository.
